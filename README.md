# Sonsuz Çay Demleyen Felsefe Makinesi

Bu, insanlık tarihinin en büyük teknolojik başarısıdır. Sadece çay demler. Ama asla bitmez. Ve her demleme esnasında evrenin sırlarını fısıldar.

## Nasıl Çalışır?

```bash
python cay_demle.py
```

Dikkat: Bu kod sonsuz döngüdedir. Ctrl+C ile kurtulabilirsiniz. Belki. Veya kurtulamazsınız. Çay sizi çağırır.

## Özellikler

- Sonsuz çay demleme
- Rastgele Türk felsefi saçmalıklar
- Asla şeker eklemez (sağlıklı)
- Evreni sorgular

## Uyarı

Bu makine çayı demlerken dünyayı kurtarabilir veya yok edebilir. Sorumluluk kabul etmiyoruz.
